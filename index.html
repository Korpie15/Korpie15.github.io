Port Container Flow Visualisation

▼

Interactive Streamlit Sankey dashboard for tracing container movements through the terminal with live filtering and analytics...

Port Container Flow Visualisation is an interactive web application built to analyse how shipping containers move through a port terminal from vessel discharge, through the yard, and out via truck or rail, as well as the reverse flow for outbound loads.

The live demo is published on Streamlit Community Cloud and uses entirely synthetic sample data, so it can be embedded publicly on a personal website without exposing any operational databases or company credentials.

The dashboard presents the container journey as a Sankey flow diagram, making it easy to see which berths, yard blocks, vessels, and transport modes drive the most volume, where re-handles occur, and where movement sequences contain data gaps.

Key Features

  • Interactive Sankey diagram with click-to-highlight path tracing
  • Sidebar filters for date range, vessel, flow direction, cargo category, berth grouping, and minimum volume threshold
  • Analytics tab with summary statistics, top routes, vessel breakdowns, and origin/destination rankings
  • Data gap diagnostics that surface orphaned or broken movement sequences
  • Step volume cards that show how container counts change across the journey

Technology Stack

  • Python and Streamlit for the application layer
  • Plotly for the Sankey visualisation
  • Pandas for filtering, grouping, and aggregation
  • Bespoke JavaScript for node and flow highlighting inside the chart

Industrial Robot Programming and Integration

▼

Fanuc robot programming for glut-handling on strapping line with vision-based detection and PLC integration...

My most recent work involved programming a Fanuc robot for use as a glut-handling robot on a strapping line at a new factory. The robot was designed to pick gluts from a stillage by scanning for the next heights glut in the stillage and then adjusting its pick position accordingly before picking the glut and then moving to the strapper channel to place the glut.

I was responsible for programming the robot's pick, place, movement and scanning sequences to detect glut locations within the stillage, as well as configuring communication between the robot and the Siemens PLC via Profinet. The robot was programmed using ls and tp code with some karel functions for more complicated sections. Fanuc Roboguide was used to simulate and test the robot before Factory Acceptance Testing (FAT) was started. This was performed within the factory where I was able to verify motion sequences, and troubleshoot integration issues between the robot, PLC, and line control systems along with testing the new SCADA interface.

This project strengthened my understanding of industrial robotics, detection logic, and robot–PLC communication protocols. It also reinforced the importance of structured testing, clear fault diagnosis, and collaboration across engineering disciplines during commissioning.

Foz Prints

Headless eCommerce platform and engineered 3D printed Subaru interior upgrades

Next.js Shopify Cloudflare 3D Printing

Live Website: fozprints.com.au

The Background
I started Foz Prints to solve a problem I had with my own Subaru Forester SG. The factory interior plastics become brittle over time. Original replacements are either discontinued or ridiculously expensive, and most aftermarket options look terrible. I decided to design, model, and manufacture my own 3d printed replacement parts in Sydney, printing them in heat resistant ASA plastic so they can actually survive an Australian summer.

The Tech Stack
I wanted full control over the design and speed of the website, so I built a headless setup instead of using a standard template.

  • Frontend: A custom Next.js site hosted on Netlify.
  • Backend: Shopify to handle the secure checkout, inventory management, and payments.
  • DNS: Cloudflare to route traffic safely between the two systems.

The Build Process and Challenges
Handling both the physical product engineering and the web development at the same time threw up some interesting roadblocks.

  • The Prototype Graveyard: Getting a 3D printed part to perfectly match a twenty year old dashboard is incredibly difficult. It took dozens of CAD iterations to get the curves, snap fits, and surface textures exactly right before the parts looked like they actually belonged in the car.
  • Headless Routing: Connecting a Next.js frontend to a Shopify checkout was a difficult task. I had to correctly map the root domain to Netlify while isolating the secure checkout on a Shopify subdomain without taking the whole site offline.
  • Working Around Locked Code: To keep running costs low, I used the basic Shopify Starter plan. This meant the backend code was completely locked down. When the headless setup caused the checkout logo to trap users on a dead end page, I could not use custom JavaScript or third party apps to fix it. I had to build native navigation workarounds to get customers back to the main site.
  • Australia Post API Limits: Getting live shipping rates to work at checkout was another massive headache. The Australia Post API is incredibly strict. If a single product weight, box dimension, or suburb spelling was slightly off, the whole checkout would crash. Figuring out exactly how to format the data to keep the API happy took a lot of trial and error.
  • Leveraging AI as a Technical Partner: Building a custom web platform alone is tough, so I heavily utilised AI tools throughout the project. I used AI to help write custom code, debug Next.js routing bugs, and translate confusing Shopify documentation. Having an AI to bounce ideas off drastically sped up the troubleshooting process, especially when fixing weird DNS and API connection issues.

Personal Server

Self-hosted infrastructure for secure remote access, automation, documentation, and media streaming

Networking Automation CasaOS Jellyfin

Infrastructure Overview
Built on an HP EliteDesk 800 G5 featuring an Intel i7 processor, this home server operates as a robust, centralised hub for network management, smart home orchestration, technical authoring, and multimedia hosting. The environment is managed via CasaOS, providing a streamlined interface for deploying and maintaining enterprise level containerised applications.

Secure Remote Connectivity
To ensure reliable access from anywhere in the world, the server utilises Tailscale. This implements a secure Zero Trust virtual private network overlay. It allows external devices to connect seamlessly to internal services without exposing any hardware to the public internet, guaranteeing strict security while maintaining complete remote accessibility.

Smart Home Orchestration
The server functions as the primary controller for a comprehensive smart home ecosystem through Home Assistant and a dedicated Matter Server. This architecture integrates various IoT devices across different protocols into a single, unified interface. By processing automations locally on the hardware, it ensures rapid response times for environment controls while completely eliminating the reliance on external cloud services.

Technical Documentation Platform
For academic and professional writing, the server hosts a local instance of Overleaf via the ShareLaTeX container. This provides a powerful, collaborative LaTeX authoring environment accessible directly through a web browser. It handles complex mathematical formatting and document compilation entirely on local hardware, ensuring complete data privacy and robust version control for all technical documents.

Personal Media Ecosystem
The system serves as a highly capable personal media library powered by Jellyfin. This platform allows for the hosting and streaming of personal digital media to any screen on the network in high definition. The user experience is augmented by Jellyseerr, which acts as a clean portal for media discovery and internal library requests. In the background, a suite of automated library management tools handles the seamless curation of metadata, artwork, and subtitle synchronisation as new content is added to the private collection.

Turtle Bot Warehousing System

Autonomous warehousing robot using ROS and lidar navigation

ROS Lidar 3D Printing

The Turtlebot warehousing robot autonomis item picking and delivery in warehouses using a scalable system of robots. Initially, a single robot maps the warehouse, creating a static map while avoiding dynamic obstacles like people or forklifts. The system assigns tasks to robots based on proximity and payload capacity, coordinating item retrieval and delivery to a drop-off zone. Using lidar, the robots dynamically avoid obstacles, including each other, to maintain efficiency.

My focus was on the payload delivery system, a 3D-printed mechanism with a servo-driven trap door. Mounted on the top of the robot, it securely carries and dispenses items from the pick-up to the drop-off zone. Controlled by an Arduino Nano that listens for a signal from the Raspberry Pi the turtle bot is running on. By being mounted above the Lidar the system minimises interference with the lidar for smooth operation.

SPOT Search and Rescue

Boston Dynamics SPOT with autonomous exploration and YOLOv3

ROS YOLO Autonomous Navigation

This group project involved leveraging the Boston Dynamics SPOT robot for search-and-rescue operations in challenging and potentially hazardous environments. We developed a ROS1 package to facilitate autonomous exploration and human detection, making the system accessible for anyone to install and use. The onboard video feed from SPOT was integrated with YOLOv3 for human identification, achieving a confidence threshold of 80%. Since the pre-trained human detection model met our needs, no additional model training was required. When a human was detected, a marker was placed on a global map, allowing rescuers to pinpoint their exact locations.

Exploration of the environment utilised a greedy frontier-based algorithm, ensuring complete area coverage. Once SPOT finished exploring, the total number of markers on the map provided the rescue team with a clear overview of all detected individuals and their locations.

This project was also a significant learning experience for me. It marked my first exposure to ROS, Linux, and Git repositories, helping me build confidence in installing and integrating different packages into robotic projects. These new skills have expanded my technical capabilities and prepared me for future projects.
